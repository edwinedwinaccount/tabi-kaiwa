# Tabi Kaiwa

A personal Japanese learning app for travel: kana-first lessons that build each phrase word by word, spaced review, voice conversations and a pocket phrasebook.

- `index.html` is the whole app. `sw.js` lets it open with no signal.
- Progress, personal details and the Claude API key are stored only in the browser of the device using it. Nothing personal is in this repository.
- `source/` holds the pieces `index.html` is built from: the app code (`source/src`) and the curriculum (`source/curriculum`).
